# Contributing to szl-trust

Thank you for helping improve the SZL Holdings public trust-artifact registry.
This repository publishes audit material and verification helpers; it is not a
live execution system.

## Contribution model

Owner-authored first-party maintenance follows the repository's current GitHub
source controls and applicable CI/security checks. An absent DCO trailer or an
unavailable second-human reviewer is not represented as evidence that does not
exist. External contributors remain subject to the rights and review terms that
apply to their contribution.

For public contributions:

1. Open an issue describing the defect or documentation change when practical.
2. Branch from current `main`.
3. Keep the change narrowly scoped and preserve historical receipts/evidence.
4. Open a pull request and address every applicable CI/security check and
   blocking review thread.
5. Do not weaken verifiers, scanners, provenance, source identity, or release
   safeguards merely to make a change pass.

Small documentation/link/factual corrections are welcome. Changes to published
run artifacts, verification semantics, license terms, or proof authority need
explicit source review and evidence appropriate to that scope.

